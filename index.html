🔗 NUBE HÍBRIDA

Definición

La nube híbrida combina infraestructura de nube pública y privada, permitiendo que datos y aplicaciones se compartan entre ellas. Ofrece lo mejor de ambos mundos: la seguridad del entorno privado y la escalabilidad del público.

Características

  • Orquestación entre plataformas
  • Portabilidad de cargas de trabajo
  • Gestión unificada
  • Bursting a nube pública
  • Cumplimiento normativo flexible

Empresas que la usan

Netflix: Usa AWS para streaming y centros propios para contenido crítico.

Airbnb: Combina AWS con infraestructura privada para datos de usuarios.

🌐 NUBE PÚBLICA

Definición

Servicios de computación ofrecidos por proveedores externos a través de internet público. Los recursos (servidores, almacenamiento) son propiedad del proveedor y se comparten entre múltiples clientes (multi-tenant).

Modelo de Pago

Pay-as-you-go: Solo pagas por los recursos que consumes. Sin inversión inicial en hardware. Escalabilidad instantánea según demanda.

Estadísticas

AWS posee el 32% del mercado. Azure el 23%. Google Cloud el 11%. El mercado de nube pública crece un 20% anual y alcanzará $800 mil millones en 2028.

🔒 NUBE PRIVADA

Definición

Infraestructura cloud dedicada exclusivamente a una organización. Puede estar on-premise o alojada por un tercero. Ofrece máximo control, seguridad y personalización.

Ventajas

  • Control total sobre datos y seguridad
  • Cumplimiento regulatorio estricto
  • Rendimiento predecible
  • Personalización completa

👥 NUBE COMUNITARIA

Definición

Infraestructura compartida por varias organizaciones con intereses comunes (misión, seguridad, cumplimiento). Puede ser gestionada internamente o por un tercero.

Ejemplos

Healthcare Cloud: Hospitales comparten infraestructura cumpliendo HIPAA.

GovCloud: Agencias gubernamentales comparten nube segura.

💡 USOS DE LA INFORMÁTICA EN LA NUBE

Almacenamiento

Google Drive, Dropbox, OneDrive. Backup automático, sincronización multi-dispositivo, versionado de archivos. Escalabilidad ilimitada.

Desarrollo

GitHub Codespaces, AWS Cloud9. Entornos de desarrollo completos en el navegador. CI/CD con GitHub Actions, Jenkins.

IA & Machine Learning

Entrenamiento de modelos con GPU/TPU. APIs de visión, lenguaje, predicción. AWS SageMaker, Google Vertex AI.

Gaming

Xbox Cloud Gaming, NVIDIA GeForce Now, PlayStation Now. Juegos AAA en cualquier dispositivo sin hardware potente.

Streaming

Netflix usa AWS para transcodificar y entregar contenido a 230M+ suscriptores. YouTube procesa 500 horas de video por minuto.

IoT

AWS IoT Core, Azure IoT Hub. Conexión de millones de dispositivos, procesamiento de telemetría en tiempo real.

⭐ PRINCIPALES VENTAJAS

Reducción de Costos

Elimina inversión en hardware. Pago por uso. Sin costos de mantenimiento de infraestructura física. Ahorro estimado del 30-50%.

Escalabilidad

Escala recursos en minutos. Auto-scaling según demanda. Soporta picos de tráfico sin degradación del servicio.

Accesibilidad Global

Acceso desde cualquier lugar con internet. Colaboración en tiempo real. CDN para entrega rápida de contenido mundial.

Recuperación de Desastres

Backup automático multi-región. RTO y RPO mínimos. Replicación en tiempo real. Continuidad de negocio garantizada.

🏢 ¿CÓMO ELEGIR UN PROVEEDOR DE SERVICIOS EN LA NUBE?

Certificaciones

Verificar cumplimiento: ISO 27001, SOC 2, HIPAA, GDPR, PCI-DSS. Los proveedores líderes mantienen múltiples certificaciones.

SLA y Uptime

AWS: 99.99% SLA. Azure: 99.95%. Google Cloud: 99.99%. Revisar compensaciones por tiempo de inactividad.

Regiones Disponibles

AWS: 32 regiones. Azure: 60+ regiones. Google Cloud: 40 regiones. Elegir cercanía a usuarios para baja latencia.

Modelo de Precios

Comparar costos: Compute, Storage, Networking, Data Transfer. Usar calculadoras: AWS Pricing Calculator, Azure Pricing Calculator.

Soporte Técnico

Planes de soporte: Basic, Developer, Business, Enterprise. Tiempos de respuesta garantizados. Soporte en español disponible.

Ecosistema

Integraciones nativas, marketplace de servicios, comunidad de desarrolladores, documentación extensa, SDKs disponibles.

📚 10 TÉRMINOS DE INFORMÁTICA EN LA NUBE

1. IaaS

Infraestructura como Servicio. Recursos de computación virtualizados (servidores, almacenamiento, redes). Ej: AWS EC2.

2. PaaS

Plataforma como Servicio. Entorno para desarrollar y desplegar apps sin gestionar infraestructura. Ej: Heroku.

3. SaaS

Software como Servicio. Apps listas para usar vía web. Ej: Google Workspace, Microsoft 365.

4. Kubernetes

Orquestador de contenedores open-source. Automatiza despliegue, escalado y gestión de aplicaciones containerizadas.

5. Docker

Plataforma para crear y ejecutar aplicaciones en contenedores. Aísla apps del sistema operativo. Portabilidad total.

6. API Gateway

Punto de entrada único para APIs. Maneja autenticación, rate limiting, versionado. Ej: AWS API Gateway.

7. Load Balancer

Distribuye tráfico entre múltiples servidores. Mejora disponibilidad y rendimiento. Soporta SSL termination.

8. CDN

Content Delivery Network. Red de servidores que entregan contenido desde ubicación más cercana al usuario. Ej: CloudFront.

9. Serverless

Ejecuta código sin aprovisionar servidores. Escalado automático. Pago por ejecución. Ej: AWS Lambda.

10. Microservicios

Arquitectura donde apps se componen de servicios pequeños e independientes. Comunicación vía APIs. Escalado granular.
