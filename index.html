🔗 NUBE HÍBRIDA

Definición

Combina nube pública y privada, ofreciendo seguridad y escalabilidad.

Características

  • Orquestación entre plataformas
  • Portabilidad de cargas
  • Gestión unificada
  • Bursting a nube pública

Empresas

Netflix: AWS + centros propios. Airbnb: AWS + infra privada.

Video Explicativo

🎥 Computación en la Nube explicada (fuente oficial)

🌐 NUBE PÚBLICA

Definición

Servicios de computación ofrecidos por proveedores externos a través de internet.

Modelo de Pago

Pay-as-you-go: pagas solo por lo que consumes.

Estadísticas

AWS: 32% | Azure: 23% | Google: 11%

🔒 NUBE PRIVADA

Definición

Infraestructura dedicada a una organización. On-premise o alojada.

Ventajas

  • Control total de datos
  • Cumplimiento regulatorio
  • Rendimiento predecible

👥 NUBE COMUNITARIA

Definición

Infraestructura compartida por organizaciones con intereses comunes.

Ejemplos

Healthcare Cloud: Hospitales. GovCloud: Gobierno.

📚 10 TÉRMINOS

1. IaaS

Infraestructura como Servicio. AWS EC2.

2. PaaS

Plataforma como Servicio. Heroku.

3. SaaS

Software como Servicio. Google Workspace.

4. Kubernetes

Orquestador de contenedores.

5. Docker

Contenedores portables.

6. API Gateway

Entrada única para APIs.

7. Load Balancer

Distribución de tráfico.

8. CDN

Content Delivery Network.

9. Serverless

Ejecución sin servidores. Lambda.

10. Microservicios

Servicios independientes.
