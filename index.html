🔗 NUBE HÍBRIDA

Definición

La nube híbrida combina infraestructura de nube pública y privada, permitiendo que datos y aplicaciones se compartan entre ellas. Ofrece lo mejor de ambos mundos: la seguridad del entorno privado y la escalabilidad del público.

Características

  • Orquestación entre plataformas
  • Portabilidad de cargas de trabajo
  • Gestión unificada
  • Bursting a nube pública
  • Cumplimiento normativo flexible

Empresas que la usan

Netflix: Usa AWS para streaming y centros propios para contenido crítico.

Airbnb: Combina AWS con infraestructura privada para datos de usuarios.

🌐 NUBE PÚBLICA

Definición

Servicios de computación ofrecidos por proveedores externos a través de internet público. Recursos compartidos entre múltiples clientes (multi-tenant).

Modelo de Pago

Pay-as-you-go: Solo pagas por lo que consumes. Sin inversión inicial en hardware.

Estadísticas

AWS: 32% del mercado. Azure: 23%. Google Cloud: 11%. Crecimiento anual del 20%.

🔒 NUBE PRIVADA

Definición

Infraestructura cloud dedicada exclusivamente a una organización. On-premise o alojada por tercero.

Ventajas

  • Control total sobre datos
  • Cumplimiento regulatorio
  • Rendimiento predecible
  • Personalización completa

👥 NUBE COMUNITARIA

Definición

Infraestructura compartida por organizaciones con intereses comunes (misión, seguridad, cumplimiento).

Ejemplos

Healthcare Cloud: Hospitales comparten infraestructura HIPAA. GovCloud: Agencias gubernamentales.

💡 USOS DE LA INFORMÁTICA EN LA NUBE

Almacenamiento

Google Drive, Dropbox, OneDrive. Backup automático, sincronización multi-dispositivo.

Desarrollo

GitHub Codespaces, AWS Cloud9. CI/CD con GitHub Actions, Jenkins.

IA & ML

Entrenamiento con GPU/TPU. AWS SageMaker, Google Vertex AI.

Gaming

Xbox Cloud Gaming, GeForce Now. Juegos AAA sin hardware potente.

Streaming

Netflix usa AWS. YouTube procesa 500h de video por minuto.

IoT

AWS IoT Core, Azure IoT Hub. Millones de dispositivos conectados.

⭐ PRINCIPALES VENTAJAS

Reducción de Costos

Sin inversión en hardware. Pago por uso. Ahorro del 30-50%.

Escalabilidad

Auto-scaling según demanda. Soporta picos de tráfico.

Accesibilidad Global

Acceso desde cualquier lugar. CDN para entrega rápida mundial.

Recuperación de Desastres

Backup multi-región. RTO/RPO mínimos. Continuidad de negocio.

📚 10 TÉRMINOS DE INFORMÁTICA EN LA NUBE

1. IaaS

Infraestructura como Servicio. Ej: AWS EC2.

2. PaaS

Plataforma como Servicio. Ej: Heroku.

3. SaaS

Software como Servicio. Ej: Google Workspace.

4. Kubernetes

Orquestador de contenedores.

5. Docker

Apps en contenedores portables.

6. API Gateway

Entrada única para APIs.

7. Load Balancer

Distribución de tráfico.

8. CDN

Content Delivery Network. Ej: CloudFront.

9. Serverless

Ejecución sin servidores. Ej: AWS Lambda.

10. Microservicios

Arquitectura de servicios independientes.
